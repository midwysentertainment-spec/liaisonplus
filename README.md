# Liaison Plus — Site vitrine

Site vitrine React/Vite prêt à déployer.

## Lancer en local

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
```

## Déployer gratuitement sur Vercel

- Créer un repo GitHub
- Importer le projet dans Vercel
- Framework : Vite
- Build command : `npm run build`
- Output directory : `dist`

## À modifier
